## Export and customer response

Create work order explicitly saves ordered recommendations, model-compatible proposed parts/quantities,
policy and baseline context, customer assignment and evidence cutoff. Existing orders use that snapshot
even if mappings change. Each candidate has readable family name/SKU/quantity 1 and a conditional label.
A sensor symptom cannot prove the first listed part is the cause.

The assigned signed-in customer can report component deterioration, sensor issue, no fault found,
incorrect recommendation or unknown; Unknown cause is available. Replacement requires compatible actual
parts and positive quantities. Inspection, connection repair and report-only actions do not require stock
operations. Completed can be Not resolved or Not sure. Rejected requires a reason and hides performed-work
fields. Rating is optional; notes are feedback only, including the word “partial”. One final response is
saved atomically; identical retries return it, conflicting responses fail visibly. No response changes sensor
evidence, physical repair efficacy, inventory or the fault's observed end.
